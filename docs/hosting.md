# Онлайн-версия для жюри

Онлайн-версия запускается командой `python app.py --public`. Она отличается от версии на компьютере:

- у каждого посетителя свой дневник: жюри не видит, что вводил другой человек;
- всё, что посетитель ввёл, удаляется через 6 часов;
- файлы (выписки, анализы) не загружаются;
- AIbert отвечает на 30 вопросов от одного посетителя, в YandexGPT уходит не больше 500 вопросов в сутки, дальше AIbert отвечает без нейросети;
- сверху висит пометка «Онлайн-версия для знакомства».

Вход по телефону и коду показывает, как будет выглядеть вход в боевой версии. СМС не отправляется, код для демо 1234, номер нигде не сохраняется. Есть кнопка «Посмотреть на примере без входа».

## Как разместить на Render (бесплатно, около 10 минут)

1. Зайдите на https://render.com и нажмите **Get Started**. Войдите через GitHub (кнопка GitHub), разрешите Render видеть репозиторий `Patient_diary`.
2. В панели Render нажмите **New → Blueprint**, выберите репозиторий `Patient_diary`. Render сам прочитает файл `render.yaml`.
3. Render попросит заполнить два поля:
   - `YANDEX_API_KEY` — ваш API-ключ YandexGPT (тот же, что в файле `.env`);
   - `YANDEX_FOLDER_ID` — идентификатор каталога (начинается с `b1g`).
   Ключ вводится только здесь, на сайте Render: в чат и в репозиторий его не пишите. Если оставить поля пустыми, AIbert будет отвечать без нейросети.
4. Нажмите **Apply** (или **Deploy Blueprint**). Через 2–3 минуты появится адрес вида `https://checkup-track.onrender.com`. Это и есть ссылка для жюри.
5. После каждого влитого PR Render сам обновит сайт за пару минут.

## Что важно знать

- **Сайт «засыпает».** На бесплатном тарифе после 15 минут без посетителей Render выключает сервер. Первое открытие после этого занимает около минуты. Перед защитой откройте ссылку за пару минут, чтобы сайт проснулся.
- **Проверьте доступ без VPN.** Откройте ссылку с телефона через мобильный интернет. Если в России сайт не открывается, напишите: перенесём онлайн-версию на Яндекс Облако.
- **Данные о здоровье.** Серверы Render находятся за пределами России, поэтому онлайн-версия только для знакомства с сервисом. Настоящие данные пациентов хранятся в версии на компьютере.
