# Прогон перед защитой

## Шаги

1. Запусти тесты: `python -m unittest`. Если хоть один падает, остановись и сообщи об этом.
2. Запусти сервер в фоне с фиксированной датой, чтобы скриншоты совпадали с README:
   `python app.py --port 8765 --today 2026-10-24`
   Не запускай его в той же команде, где потом ищешь или останавливаешь процесс: `pkill -f app.py` убьёт и саму команду.
3. С помощью Playwright (`require('playwright')`, `chromium.launch()`) пройди сценарии на двух размерах окна: 1200×900 и 390×844 (телефон).
   - **Анна** (`anna`): главная с солнцем, «Мой план» (раскрыть «Просрочено», блок «Прививки»), окно «Как подготовиться» у маммографии, ссылка «Отказали в поликлинике?» → «Составить текст».
   - **Мария** (`mariya`): солнце горит целиком.
   - **Пётр** (`petr`): прививка от гриппа, календарь.
   - **Без даты рождения** (`no_birth_date`): понятное объяснение, а не ошибка.
   - Вкладка «Пройдено»: карточка «Проверьте, нет ли приписок».
   - Памятка `/report`: блоки «Как подготовиться» и «Взять с собой».
4. На каждом экране проверь:
   - нет ошибок в консоли (`pageerror`, `console.error`);
   - на телефоне нет горизонтальной прокрутки (`document.documentElement.scrollWidth <= 390`).
5. Сохрани скриншоты в `/mnt/project-files/screenshots/demo-run-ГГГГ-ММ-ДД/` с понятными русскими именами: `1_главная_анна.png` и т. д.
6. Останови сервер. Пришли пользователю короткий итог: что проверено, что сломано (со скриншотом), и где лежат картинки.

Данные демо-пациентов вымышленные. Не загружай настоящие данные пользователя из `data/user/`.
